# PotionSwirlKernel

An attempt to write my own kernel for an x64 computer. I KNOW Linux is available for that, but writing my own drivers teaches me a lot and is just...fun 💝.

We're using WSL Ubuntu to make this. Even though the latest version is 26.04 LTS, we've been using the same toolchain from 2024 and our Makefile breaks when we use it on 26.04, so we'll just stick to 24.04 for now... 👍
